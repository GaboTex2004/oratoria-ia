# CU-24 Administración — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Completar el módulo de administración del Documento Grupal (categorías, planes, parámetros del sistema, estado de módulos y estadísticas) sobre el panel `/admin` existente.

**Architecture:** Paquete backend `com.oratoria.backend.admin` crece con un controlador/servicio por área (categorías, planes, ajustes, salud, estadísticas). Nueva migración Flyway `V5__admin_system.sql` con `exercise_categories` y `system_settings`. El frontend divide `AdminManagementPage` en pestañas con un componente por área.

**Tech Stack:** Spring Boot 4, Java 21, JPA + Flyway, PostgreSQL, React 19 + TS + Vite.

**Spec:** `docs/superpowers/specs/2026-11-17-admin-cu24-design.md`

## Global Constraints

- Todo endpoint nuevo bajo `/api/admin/**` (ya exige `ROLE_ADMIN`), salvo `GET /api/system/announcement` (autenticado).
- `ddl-auto=validate`: toda tabla/columna nueva va en `V5__admin_system.sql`.
- Errores de validación de negocio → `BadRequestException` (400); no encontrado → `ResourceNotFoundException` (404); registro cerrado → `AccessDeniedException` (403).
- Pruebas: `@SpringBootTest @AutoConfigureMockMvc @Transactional`, usuarios creados como en `LocalCapabilitiesIntegrationTests.user(role)`, base de prueba con `TEST_DB_URL=jdbc:postgresql://127.0.0.1:55435/oratoria_test`.
- Textos de UI en español; reutilizar `WorkspaceLayout`, `useResource`, `apiRequest`, clases `panel-card`, `workspace-table`, `workspace-form`, `button`.

## Review Focus

- Desactivar una categoría con ejercicios activos: los ejercicios existentes siguen visibles, pero no se pueden crear ejercicios nuevos en ella → test en Task 1.
- Límite de plan negativo o `unlimited=true` con valor: 400 y `unlimited` ignora el valor → test en Task 2.
- Parámetro con valor fuera de rango (`audio.max-duration-seconds=5` o texto) → 400 sin guardar → test en Task 3.
- Servicio de IA caído o lento: el estado responde en ≤ 3 s con `DOWN`, no un 500 → test en Task 4.
- Estadísticas con base vacía (sin evaluaciones): listas vacías, no error → test en Task 5.
